# Relational Gospel Atlas

An interactive, animated study atlas of the relational gospel: Jesus as the perfect theology, separation vs union, the purpose of the Law (64 laws explained), the violent passages, how people misread God, Old/New Testament tensions, a culture decoder (38 customs, starting with the sandals), 44 sayings of Jesus in their setting, the great themes, common teachings, strawmen, real debates, and a reading compass for approaching the Bible.

- `src/` – page template, styles, app script and content data (`src/data/*.js`)
- `node build.js` – inlines everything into `index.html` (any static host, e.g. GitHub Pages) and `dist/artifact.html`
